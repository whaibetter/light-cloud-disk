# 需求文档

> 轻量云盘 (Light Cloud Disk) 产品需求说明

## 1. 产品概述

### 1.1 产品定位

轻量云盘是一个**自托管的轻量级文件管理系统**，面向个人用户和小型团队，提供跨平台的文件上传、管理、下载功能。

### 1.2 目标用户

- 需要在多设备间同步文件的个人用户
- 需要简单文件共享的小型团队
- 希望自主掌控数据隐私的用户

### 1.3 核心价值

- **轻量部署**：单文件 Node.js 服务，无需数据库，JSON 文件存储元数据
- **跨平台**：基于 Uni-app，支持 Web、Android、iOS、微信小程序
- **开箱即用**：配置简单，部署快速

## 2. 功能需求

### 2.1 文件管理

#### 2.1.1 文件上传

| 需求项 | 说明 |
|--------|------|
| 单次上传数量 | 最多 10 个文件 |
| 单文件大小限制 | 可配置，默认 100MB |
| 文件名处理 | 自动修复中文文件名编码问题 |
| 重名处理 | 自动添加数字后缀 `(1)`, `(2)` ... |
| 上传进度 | 实时显示上传百分比 |
| 平台差异 | H5 使用 XMLHttpRequest，App 使用 uni.uploadFile |

#### 2.1.2 文件列表

| 需求项 | 说明 |
|--------|------|
| 视图模式 | 列表视图 / 网格视图，可切换 |
| 文件信息 | 显示文件名、大小、上传时间、文件类型图标 |
| 搜索 | 按文件名模糊搜索，忽略大小写 |
| 排序 | 支持按名称/时间/大小排序，升降序可选 |
| 类型筛选 | 支持按文件类型筛选：图片/视频/音频/文档/压缩包 |

#### 2.1.3 文件下载

| 需求项 | 说明 |
|--------|------|
| 下载方式 | H5 通过 `<a>` 标签下载，App 通过 uni.downloadFile |
| 中文文件名 | 使用 RFC 5987 编码，确保正确显示 |
| 流式传输 | 服务端使用流式传输，支持大文件下载 |

#### 2.1.4 文件删除

| 需求项 | 说明 |
|--------|------|
| 删除确认 | 删除前弹出确认对话框 |
| 同步更新 | 删除后自动刷新文件列表 |

### 2.2 配置管理

| 需求项 | 说明 |
|--------|------|
| 服务器地址 | 用户可配置后端服务器 URL |
| API Key | 用户可配置认证密钥 |
| 连接测试 | 支持测试服务器连接是否正常 |
| 配置持久化 | 配置保存到本地存储，应用重启后保留 |
| 恢复默认 | 支持一键恢复默认配置 |

### 2.3 主题系统

| 需求项 | 说明 |
|--------|------|
| 浅色模式 | 默认主题，明亮配色 |
| 深色模式 | 暗色配色，护眼 |
| 主题切换 | 一键切换，实时生效 |
| 持久化 | 主题选择保存到本地存储 |

### 2.4 响应式布局

| 需求项 | 说明 |
|--------|------|
| 移动端布局 | < 768px，单栏布局，底部 TabBar |
| 桌面端布局 | >= 768px，侧边栏 + 主内容区 |
| 自适应 | 自动根据屏幕宽度切换布局 |

## 3. 非功能需求

### 3.1 平台兼容性

| 平台 | 支持状态 |
|------|----------|
| Web (H5) | 支持 |
| Android | 支持 (Uni-app 原生壳 + Cordova 壳) |
| iOS | 支持 (Uni-app) |
| 微信小程序 | 支持 |

### 3.2 性能要求

| 指标 | 要求 |
|------|------|
| 网络超时 | 30 秒 |
| 页面加载 | 首屏渲染 < 3 秒 |
| 文件上传 | 支持进度回调 |
| 文件下载 | 流式传输，不占用过多内存 |

### 3.3 安全要求

| 要求 | 说明 |
|------|------|
| API 认证 | 所有 API（除健康检查）需 API Key 认证 |
| 密钥存储 | 前端密钥存储在本地，不明文展示（可切换显示） |
| CORS | 支持配置允许的域名白名单 |
| 文件大小限制 | 防止恶意大文件上传 |

### 3.4 数据存储

| 项目 | 说明 |
|------|------|
| 元数据存储 | JSON 文件 (`server/data/files.json`) |
| 文件存储 | 服务器本地文件系统 (`server/uploads/`) |
| 前端配置 | Uni-app 本地存储 (`uni.storage`) |

## 4. 用户故事

### 4.1 文件上传

> 作为用户，我希望能从手机或电脑上传文件到云盘，以便在不同设备间访问这些文件。

**验收标准**：
- 支持选择单个或多个文件上传
- 显示上传进度
- 上传完成后文件出现在列表中
- 中文文件名正确显示

### 4.2 文件管理

> 作为用户，我希望能方便地查找、浏览和管理我的文件。

**验收标准**：
- 支持按文件名搜索
- 支持按类型筛选
- 支持按名称/时间/大小排序
- 支持列表和网格两种视图

### 4.3 文件下载

> 作为用户，我希望能下载云盘中的文件到本地设备。

**验收标准**：
- 点击下载按钮即可下载
- 下载的文件名正确（含中文）
- 大文件能正常下载

### 4.4 跨平台使用

> 作为用户，我希望能在手机和电脑上都能使用这个云盘。

**验收标准**：
- Web 浏览器可正常访问
- Android App 可正常使用
- 移动端和桌面端有各自适配的布局

### 4.5 个性化配置

> 作为用户，我希望能配置自己的服务器地址和 API 密钥。

**验收标准**：
- 设置页可输入服务器地址和 API Key
- 支持测试连接是否正常
- 配置保存后持久化
- 支持恢复默认配置
