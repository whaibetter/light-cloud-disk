# Tab Bar Icons

This directory should contain tab bar icons for the application.

Required files:
- tab-files.png (32x32px, normal state)
- tab-files-active.png (32x32px, selected state)
- tab-settings.png (32x32px, normal state)
- tab-settings-active.png (32x32px, selected state)

For development, you can use any PNG images. For production, ensure icons are properly sized and optimized.

## Placeholder Solution

If you don't have icons yet, you can:
1. Use any 32x32 PNG images
2. Or use the HBuilderX built-in icon generator
3. Or download from icon libraries like Material Design Icons
